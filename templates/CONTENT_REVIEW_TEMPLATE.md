## Accuracy and coverage

- [ ] Exact original source concepts mapped, including non-obvious pitfalls
- [ ] Nothing essential omitted or mischaracterized
- [ ] Working code examples validated in intended environment
- [ ] External dependencies/version assumptions clearly named
- [ ] No instructor-only solution unintentionally published

## Self-learning quality

- [ ] Explains why the topic matters and what prerequisites it needs
- [ ] Defines terminology and gives clear mental model
- [ ] Has worked example plus meaningful independent application
- [ ] Hints address likely misconceptions
- [ ] Works without mandatory YouTube/AI/network dependency

## Assessment and progression

- [ ] Each required checkpoint maps to a learning outcome
- [ ] Correct answers and wrong-answer feedback reviewed
- [ ] Quiz bank avoids trivial copy and guess-through patterns
- [ ] External project outcomes labeled self-verified honestly
- [ ] Required gates, dependencies and IDs correct

## UI/accessibility checks

- [ ] Keyboard and screen-reader semantics
- [ ] Light/dark contrast and long-code wrapping
- [ ] Desktop and mobile readability
- [ ] Error, retry and locked states explained
