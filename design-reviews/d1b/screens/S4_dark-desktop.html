Why forms need
real labels

A form should make sense to everyone—including someone using a keyboard or screen reader. Start with meaningful HTML before adding JavaScript.

HTML fundamentals1 of 2 checks pending

The label is part of the interface

When a <label> uses for with an input's id, clicking the label focuses the correct field. The relationship also gives assistive technology a name for the input.

index.html · worked exampleHTML
<form>
  <label for="task-title">Task title</label>
  <input id="task-title" required />
  <button type="submit">Add task</button>
</form>
Field note. The required attribute catches an empty input. It does not reject a title containing only spaces—JavaScript validation will handle that later.
TRY IT YOURSELF

Click the visible label in the preview. Does the cursor move into the text field? Then identify what breaks if for and id do not match.
