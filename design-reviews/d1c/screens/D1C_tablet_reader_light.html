Why forms need real labels

An accessible form begins with meaningful HTML, not JavaScript tricks. Learn to connect labels to fields and make forms understandable to every learner.

HTML fundamentals1 of 2 checks pending
After this lesson, you can
  • Associate a label with its input
  • Explain what native validation handles
  • Build a semantic task-entry form

A label is part of the interface

When a <label> uses for to match an input's id, clicking the label focuses the field. This relationship also gives assistive technology the input's name.

index.html · worked exampleHTML
<label for="task-title">Task title</label>
<input id="task-title" required />
<button type="submit">
  Add task
</button>
Field note. required catches an empty input, but a title made of spaces still needs JavaScript validation.
